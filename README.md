# دوريسيو — Dorisio

> **دوريكم... بشكل حقيقي.**
> منصة دوري كرة القدم للمدارس والأصدقاء: جدول ترتيب، مباريات مباشرة، خط زمني للأحداث،
> إحصائيات اللاعبين، التقييمات، الجوائز، وسجل مواسم دائم — مع تطبيق PWA يعمل دون اتصال.

---

## لماذا دوريسيو؟

دوريسيو ليس لوحة تحكم عامة. الواجهة مبنية على لغة البث التلفزيوني لكرة القدم: شريط
نتائج يمتد من حافة الشاشة إلى الأخرى، أرقام مضغوطة كأرقام النتائج، جدول ترتيب بخطوط
شعرية كجداول الصحف الرياضية، وخطوط ذهبية لا تُستخدم إلا للأبطال والجوائز.

**اللحظة التي تبقى في الذاكرة:** الهدف المباشر — يمرّ بريق ذهبي فوق شريط النتيجة،
تتحرّك خانة النتيجة، يظهر اسم اللاعب بخط ضخم، ويقفز صف الفريق في الترتيب.

## الميزات الأساسية

| المجال | ما تم بناؤه |
| --- | --- |
| **الحسابات** | تسجيل/دخول ببريد وكلمة مرور (scrypt)، جلسات محفوظة على الخادم، استعادة كلمة المرور، تحديث الملف الشخصي |
| **OAuth** | Google / GitHub / Facebook عبر تدفّق Authorization Code حقيقي مع `state` وحماية CSRF |
| **الأدوار** | `user` / `admin` — التحقق يتم على الخادم في كل عملية، ولا يمكن اختيار «مدير» عند التسجيل |
| **البطولة** | بطولات ومواسم متعددة، حالات (قادم/جاري/منتهي)، بطل الدوري، حفظ دائم للتاريخ |
| **الفرق** | ألوان، شعارات، قوائم، قائد، صفحة فريق كاملة (نتائج، شكل، مباريات، إحصائيات) |
| **اللاعبون** | بطاقات مميزة، مركز بالعربية، رقم القميص، أهداف/تمريرات/بطاقات/تقييم/رجل المباراة |
| **الجدول** | مولّد مباريات Round-Robin يعالج الأعداد الفردية بالراحة (bye)، أو إضافة يدوية |
| **الترتيب** | 3 نقاط للفوز، يُحتسب تلقائياً من البيانات الرسمية للمباريات — لا تخزين مكرر |
| **مركز المباراة** | أزرار كبيرة (هدف/تمريرة/بطاقات/تبديل) تعمل بسرعة من الهاتف بجانب الملعب |
| **الزمن الحقيقي** | SSE + رقم مراجعة للمباراة: كل متصل يرى الهدف فوراً دون تحديث الصفحة |
| **سلامة البيانات** | معرّف حدث يُولَّد على الجهاز + `ON CONFLICT DO NOTHING` + إعادة احتساب النتيجة من الأحداث دائماً |
| **التشكيلة** | ملعب تكتيكي من الأعلى، تشكيلة أساسية وبدلاء، خطط لعب |
| **التقييمات** | 1–10 بعد المباراة النهائية فقط، للاعبين المشاركين فقط، بدون تكرار |
| **الجوائز** | لاعب الأسبوع، الهداف، أفضل لاعب، أفضل حارس، البطل، رجل المباراة |
| **الإعلانات** | إعلانات بطابع كرة قدم تظهر في الصفحة الرئيسية |
| **PWA** | manifest + service worker + تخزين مؤقت للغلاف + صفحة عمل دون اتصال + تثبيت |
| **دون اتصال** | تخزين IndexedDB للبيانات + طابور أحداث آمن للمزامنة عند عودة الاتصال |
| **الإشعارات** | بنية Web Push/FCM جاهزة + صندوق إشعارات داخل التطبيق |

## البنية

```
src/
  app/                    # صفحات ومسارات API (App Router)
    api/                  # مسارات الخادم: auth, overview, matches, events, ratings, ...
    admin/                # لوحة الإدارة + مركز المباراة المباشر
    matches/ table/ players/ teams/ history/ auth/ profile/ offline/
  components/             # مكونات الواجهة (brand, match, standings, player, pitch, admin, ui)
  db/                     # Drizzle ORM: schema.ts + client
  lib/
    auth.ts               # كلمات المرور، الجلسات، حماية المسارات
    league.ts             # احتساب الترتيب والإحصائيات (منطق الأعمال)
    match.ts              # إعادة احتساب النتائج، حزم البيانات
    oauth.ts              # مزودو OAuth الحقيقيون
    client/               # طبقة المتصفح: جلب البيانات، IndexedDB، الجلسة
public/
  sw.js                   # Service Worker
  manifest.webmanifest    # ملف PWA
  icon.svg, icon-maskable.svg
  images/                 # صور الهوية (استاد، ملعب، بطولة، تجهيزات)
```

فصل واضح: **منطق الأعمال** في `src/lib`، **الوصول للبيانات** في `src/db`،
**الواجهة** في `src/components` و`src/app`.

## التشغيل محلياً

```bash
# 1) المتطلبات: Node 20+ و PostgreSQL 15+
cp .env.example .env          # ثم عدّل DATABASE_URL
npm install

# 2) قاعدة البيانات
npx drizzle-kit push          # إنشاء الجداول مباشرة

# 3) التطوير
npm run dev                   # http://localhost:3000

# 4) التحقق
npm run typecheck
npm run build
```

لإنشاء أول مدير للدوري، اقرأ [SETUP.md](./SETUP.md) — القسم «إنشاء أول مدير».

## ملاحظة تقنية مهمة

بيئة التشغيل هذه تزوّد **PostgreSQL + Drizzle ORM** كقاعدة بيانات حقيقية (وليس
تخزيناً محلياً أو بيانات وهمية)، لذلك طُبِّقت طبقة البيانات والعلاقات والتكاملات
عليها بنفس التصميم المطلوب لمجموعات Firestore (users, leagues, teams, players,
matches, matchEvents, lineups, ratings, awards, announcements, notifications).
مصادقة OAuth (Google/GitHub/Facebook) مبنية بتدفّق Authorization Code حقيقي وتُفعَّل
بإضافة مفاتيح المزوّد في `.env` كما هو موثّق — بدون أي بيانات دخول وهمية.
